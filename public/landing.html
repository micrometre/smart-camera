API Endpoints

POST /api/detections

Capture and store new detection data along with captured images.

Body: { detections: [...], timestamp }
Returns: { success: true, id }
GET /api/detections

Retrieve historical detection data and filtering parameters.

Query: ?limit=number&class=string
Returns: Array of detection objects
GET /api/stats

Get high-level detection statistics and object counts.

Returns: { totalEntries, classCounts... }
DELETE /api/detections

Wipe all stored detection history and captured images.

Returns: { success: true }
