Storage Architecture

Origin Private File System

The app uses the browser's OPFS to guarantee persistent, high-performance local storage.

SQLite-WASM

Compiled to WebAssembly, SQLite runs entirely in the browser using the OPFS Virtual File System.

COOP / COEP Enabled

Cross-Origin isolation ensures security and enables SharedArrayBuffer for high-speed file operations.

Advanced Features

🧠 AI Model Optimization

The COCO-SSD model is optimized for real-time performance with the MobileNet V2 architecture, providing fast inference while maintaining high accuracy across 80 object categories.

  • Lite model for faster loading and inference
  • Supports both WebGPU and WebGL backends
  • Automatic GPU acceleration detection
  • Fallback to WebGL when WebGPU unavailable

💾 Local-First Architecture

By leveraging the Origin Private File System (OPFS), all data persistence happens entirely on the client, eliminating the need for complex backend databases.

  • Persistent local SQLite database
  • No cloud storage fees or limits
  • Instant access to stored data
  • Works entirely offline

⚡ Secure Browser Environment

The app enforces Cross-Origin Opener and Embedder policies (COOP/COEP) to create an isolated, secure environment required for high-performance memory operations.

  • SharedArrayBuffer enabled
  • Strict Cross-Origin Isolation
  • Secure, sandboxed data storage
  • Bypasses ephemeral storage issues

🎨 Modern UI/UX Design

Built with Material Design principles and modern CSS techniques for a polished, responsive interface that works across all devices.

  • Material Design 3 color system
  • Responsive grid layouts
  • Touch-friendly controls for mobile
  • Smooth animations and transitions

🔒 Privacy & Security

All computer vision processing happens entirely in your browser, ensuring your camera feed never leaves your device without your consent.

  • Local-only processing (no cloud AI)
  • No data sent to external servers
  • Optional backend for data persistence
  • HTTPS encryption for API communications
